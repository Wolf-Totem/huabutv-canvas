## 0. 已拍板

1. **容量商品 = 加购素材空间**。加在 `storageBonusBytes` 上，不过期，不改套餐档位。
2. **订阅卡放在现有钱包弹层里横滑**。不新开全页，不改默认首页。
3. **不做自定义套餐**。商店只卖 VIP、SVIP 的月 / 季 / 年（6 条）。后台不能新增会员种类。
4. **功能不切割，只切割容量。** 模块清单只用于订阅卡展示。VIP / SVIP 卡展示「含全部平台功能」。未开通用户在展示上会看到部分进阶功能「不可用」，**只是展示，入口和接口都不拦。**
5. **赠送积分、套餐容量不写死。** 后台「订阅信息」里改，下单一刻写入订单快照；支付成功后按快照生效。
6. **有效 SVIP 不能买 VIP**（到期前都不行）。**任意会员剩余超过 30 天，不能买其他会员。**
7. **新会员规则只在购买成功后生效。** 改后台价/积分/容量不影响已付订单。
8. **已开通 VIP 或 SVIP，并且启用了个人桶：写入和容量条都以个人存储为准，不再走、也不再展示云存储配额。**

刻意不做：按套餐锁导演台 / 短剧 / Agent 等真实能力；按套餐改并发；花呗；自动续费；退款；改汇付；动 `handler/agent.go`；广场 ingest；`CANVAS_AUTO_MIGRATE=true`。

## 2. 容量：现网已经在切，这一期接着用

解析顺序（`ResolveEffectiveStoredFileBytes`，已上线）：

1. 管理员给该用户写了覆盖 → 用覆盖值  
2. 否则：高级/VIP/SVIP **仍在有效期内** 且套餐容量 > 0 → 用 `planStorageQuotaBytes`  
3. 否则 → 运行策略 `storedFileGB`（默认 20GB）  
4. 上面任一结果再 **加上** `storageBonusBytes`（兑换或以后的容量包），上限 3TiB  

写入平台桶时按这个有效字节卡上传；个人桶目的地现网已经 **跳过** 这道平台配额（仍受日上传、单文件限制）。

这一期对容量的改动只有：

- 六张卡的 `storageQuotaBytes` 改成后台可编辑，开通时写入用户的 `planStorageQuotaBytes`（本来就会覆盖）。
- 增加可买的容量包（bonus）。
- 侧栏/素材页：启用个人桶时，**不要再拿云配额当总容量展示**（现网 bug：接口已经算出 `personalStoredFileBytes`，容量条却仍用平台已用 / 套餐总量）。

不要再做第二套配额引擎。

## 5. 六张订阅卡

SKU 固定。后台可改名称、售价、划线价、**赠送积分、套餐容量**、角标、强调、上下架、排序。不可改 SKU、档位、时长，不可新增第七种会员。

种子只是上架初值，**入账必须以当时商品表为准，禁止再走 `MembershipSKUSpec` 写死的 300 积分 / 1GiB。**

| SKU | 档 | 时长 | 建议初值售价 | 建议初值积分 | 建议初值容量 | 强调 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| `vip_month` | VIP | 30 天 | ¥30 | 2,888 | 30 GB | 否 |
| `vip_quarter` | VIP | 90 天 | ¥80 | 8,888 | 30 GB | 否 |
| `vip_year` | VIP | 365 天 | ¥288 | 34,888 | 30 GB | 否 |
| `svip_month` | SVIP | 30 天 | ¥68 | 6,888 | 80 GB | 是 |
| `svip_quarter` | SVIP | 90 天 | ¥180 | 20,888 | 80 GB | 是 |
| `svip_year` | SVIP | 365 天 | ¥680 | 82,888 | 80 GB | 是 |

同档月/季/年默认容量相同；运营若把年卡改成 200GB，以后买年卡的人按新值，**已经买过的人仍按当时订单快照**。

### 5.1 旧 SKU

`permanent`、`advanced_month/quarter/year`：留行、商店下架。历史订单和旧兑换码仍按**当时快照**入账。前台身份：有效 `vip_*` 显示 VIP，有效 `svip_*` 显示 SVIP；仍在期的旧 `advanced_*` 显示为 VIP。已开通永久的人，个人桶资格保留。

### 5.2 购买资格（替换现网 `AssertCanPurchaseMembership`）

现网：剩余 > 30 天不能买高级；**没有**「SVIP 不能买 VIP」。

改为：

| 当前状态 | 可买 |
| --- | --- |
| 无有效会员 | 任意在售 VIP / SVIP |
| 有效会员且剩余 **> 30 天** | **谁都不能买**（含续同一张、含升级） |
| 有效 **VIP** 且剩余 **≤ 30 天** | 可买在售 VIP 或 SVIP |
| 有效 **SVIP** 且剩余 **≤ 30 天** | **只能买 SVIP**，不能买 VIP |
| 有效 SVIP 但已到期 | 同「无有效会员」 |
| 有未完成订阅单 | 谁都不能新开，只能继续支付 |
| 未定价（0 分） | 不能在线买 |

文案：

- 剩余 > 30 天：「当前订阅剩余超过 30 天，暂不可购买其他会员」  
- SVIP 未到期点 VIP：「SVIP 有效期内不能改买 VIP，到期后再选」  

兑换码、管理员赠送：兑换走同一套资格（避免兑一张 VIP 把有效 SVIP 改掉）。管理员赠送可绕过 30 天和降档限制，但仍写审计。

### 5.3 购买成功后才改规则（快照）

下单时把商品行上的 **售价、赠送积分、套餐容量、时长、SKU/档位** 写入 `payment_orders`，之后后台改商品不影响这张单。

支付成功（或兑换成功）同一笔事务里：

1. 赠送积分按**订单快照**入账（可以是 0）。  
2. `advancedPlanSku` / 档位改成这张单的 SKU。  
3. `planStorageQuotaBytes` **覆盖**为这张单的容量（不是和旧容量 max，也不是等旧套餐到期再切）。  
4. 到期时间：若当前仍有效，在旧到期日上 **加上** 本单时长；否则从现在起算。  
5. `storageBonusBytes` 不动。管理员容量覆盖不动。  
6. 个人桶是否启用不动；只改「有没有资格开个人桶」。

「新会员规则只在购买后生效」= 未支付不算会员；支付完成当下就按新快照，不等到旧卡自然过期。

续费例子：VIP 还剩 10 天时买 SVIP 年卡 → 立刻变成 SVIP、立刻用年卡那时的容量/积分礼包，到期日 = 原到期 + 365 天。

## 6. 个人桶优先于云存储

### 6.1 谁能开

现网：平台 `allowUserS3` **且** `PermanentActive`。

改为：平台允许个人桶 **且**（永久 **或** 有效 VIP **或** 有效 SVIP）。未开通不能启用。VIP 和 SVIP 一样，不把个人桶写成 SVIP 专属（和功能不切割一致；卡上仍可把个人桶画在「进阶」里给未开通看）。

过期后：已保存的桶配置保留，但视为未启用目的地，新上传回到平台桶，并重新按云配额卡。

### 6.2 启用之后（VIP/SVIP 已配好个人存储）

现网已经：新上传、新生成优先写个人桶，且个人目的地不占平台配额。

这一期补齐产品口径：

| | 未开个人桶 | 已开个人桶 |
| --- | --- | --- |
| 新文件写到哪 | 平台云存储 | **只写个人桶**，不再写云 |
| 配额卡不停？ | 卡套餐云容量 + bonus | **不卡套餐云容量**（仍可卡日上传、单文件） |
| 侧栏 / 素材页 / 钱包容量 | 已用云文件 / 云总容量 | **只展示个人存储已用**，标题改为「个人存储」 |
| 云套餐 30/80GB、加购包 | 展示并生效 | **不展示、不作为上限** |
| 历史已在云上的文件 | 计入云已用 | 仍留在云上，但容量条不再拿云配额吓唬用户 |

容量条个人模式：

- 已用 = 现有 `personalStoredFileBytes`（个人目的地就绪文件）。  
- 总容量不套用 `effectiveStoredFileBytes`。没有个人桶配额就只显示「已用 xx · 个人存储」，不画「xx / 30GB」。  
- 加购按钮：个人模式下改为「管理我的存储」进设置，或隐藏「充云容量」；云容量包仍可在钱包容量 Tab 买，但文案写明「仅在未使用个人桶时计入平台配额」。

设置页文案从「开通永久订阅后才能使用个人存储」改为「开通 VIP 或 SVIP 后可启用；启用后新文件只进个人桶，工作台容量条改为个人已用。」

## 7. 容量加购、积分包

容量包：`topup_products.kind = storage_topup`。支付成功 `storageBonusBytes += 快照字节`。不改会员档、不改到期。

建议四档（运营可增删改价，这不是会员种类）：+20 / +50 / +100 / +200 GB。

积分包：现有 `credit_topup`，只加积分。

兑换码三种不变。新会员码的 `planSku` 用六条新 SKU；兑换入账读 **当前商品表**（或批次快照，二选一，推荐下单/兑码时快照，避免运营改容量后旧码暴发）。

## 9. 后台「订阅信息」

支付充值 → 订阅商品：固定 6 行，**没有新增**。

编辑字段：

| 字段 | 可改 | 生效 |
| --- | --- | --- |
| 名称、说明 | 是 | 立即（展示） |
| 售价、划线价 | 是 | 新订单 |
| **赠送积分** | **是（本期补上）** | 新订单快照 |
| **套餐容量 GiB** | **是（本期补上）** | 新订单快照 → 支付成功覆盖用户套餐容量 |
| 角标、强调、排序、上下架 | 是 | 立即（展示） |
| SKU、档位、时长 | 否 | — |

现网 `UpdateMembershipProduct` 只能改名称/说明/价格/上下架/排序，积分和容量列在库里却被 `MembershipSKUSpec` 和后台表单丢掉。第一刀把 PATCH 和表单补上，兑换/入账改读快照或商品行。

权益清单：只读预览「全部平台功能 + 未开通展示用的进阶列表」，不开放给运营改条目（不做自定义套餐）。

积分商品、容量商品仍可新增。渠道 / 订单 / 对账不动业务含义。

## 10. 接口与迁移（确认后才写）

schema **46**：

- 订阅商品：`tier`（vip|svip）、`original_amount_fen`、`badge`、`highlighted`。积分、容量列已存在。  
- 充值商品：`kind`、`storage_bytes`。  
- 订单：`product_kind` 增加 `storage_topup`（快照容量继续用已有 `storage_quota_bytes`）。

种子 6 条新 SKU；旧 4 条 `enabled=false`。

- `PATCH /admin/membership/products/:id`：允许 `creditsMicrocredits`、`storageQuotaBytes`；禁止改 sku / durationDays / tier。  
- `GET /membership/products`：带档位、划线、角标、积分、容量、展示用 `featureLines`（服务端按「未开通/会员」模板填，不入库运营自定义）。  
- `GET /membership`：购买资格按 §5.2；增加「是否正在用个人桶」供钱包顶栏切换。  
- `GET /resources/storage-usage`：个人桶启用时 `usedBytes/totalBytes` 改为个人已用、total 为 0 或省略，并带 `storageDisplay=personal|platform`，避免前端继续拿云配额画进度条。  
- `POST /payments/orders`：`membership | credit_topup | storage_topup`。  
- `PersonalStorageAllowed`：永久或有效 VIP/SVIP。  
- 兑换会员：不要 `MembershipSKUSpec` 写死容量。

`CANVAS_AUTO_MIGRATE` 仍 false。不改默认首页。落地页 VIP/SVIP 文案已在，等商品上架后再说要不要读接口。

## 11. 验收（确认后的第一刀）

- 商店只有 6 张卡；后台能改某张卡的赠送积分和容量，再买的人按新值，旧单不变。  
- 未开通云容量仍是默认约 20GB；买 VIP 后变成该卡容量；过期回到默认；bonus 还在。  
- 剩余 > 30 天无法买任何会员；SVIP 未到期无法买 VIP；VIP 最后 30 天可以买 SVIP，成功后立刻按 SVIP 快照。  
- 功能：未开通也能进短剧/导演台；卡上仍显示进阶不可用。  
- 开通 VIP/SVIP 后能开个人桶；启用后新文件进个人桶，侧栏只显示个人已用，不显示 30/80GB 云额度。  
- 容量包只加 bonus；积分包只加积分。  
- 旧永久用户个人桶仍可用。

## 12. 风险

- 未开通卡上写「进阶不可用」但点得进去，会有人问。用「套餐权益展示，平台功能均开放；会员主要提升云存储与开通礼包」压住预期。  
- 个人桶没有平台侧上限，大文件只受日上传/单文件；要在设置里写清。  
- 汇付收银台若仍关闭，六张卡同样付不了，与商品方案无关。  
- 运营把月卡容量改成 1GB 会立刻影响新购用户，后台加确认文案即可。
