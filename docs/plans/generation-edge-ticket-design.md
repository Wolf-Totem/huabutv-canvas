## Overview

服务器不再假装在「算图」。佳速等厂商才做生成。影策这边只做四件事：**认人、开票、记账、把成品收进自己的桶**。

用户点生成时：

1. 浏览器向服务器要一张**任务票**（鉴权、会员、积分、过期时间一次算清）。
2. 票不过：积分不够或时间过期 → **直接拒绝**，不打模型。
3. 同一张票 **只能提交一次生成**。
4. 真正打电话给模型：
   - **用户自己的 API**：浏览器本地 Worker 提交；拿到厂商 `task_id` 立刻写回服务器。
   - **平台渠道（佳速等）**：仍由可信侧提交（现阶段 Go Worker；日后可换 CF Worker 验票后代交）。平台 Key **永不进浏览器**。
5. 异步任务（佳速出图/出视频）：关浏览器也要继续查，查到后把文件拉进 **本站 R2 私有桶**，库里只存自己的 object key。
6. 预览只用 **私有桶短时签名 URL**，不用厂商临时播放地址。
7. 同步请求：浏览器断了就算丢，不续跑。
8. 云端 Agent：后台开关，**默认关**。打开后首次进页/点 Agent 时，本地没有配置就从服务端拉取再启动。Agent 循环尽量在用户侧，避免千人堆在一台 VPS 上转圈。
9. 服务器 **不装 ffmpeg**。导出用浏览器 wasm；缺文件从 R2 拉。
10. 支付 Worker **先留在服务器**。

---

## Goals & Non-Goals

### Goals

- 积分不足、会员过期、票过期 → 不能使用生成/Agent 需要模型的服务。
- 同一票根禁止第二次提交生成（幂等）。
- 素材与成品走私有 R2（或个人私有桶），短时签名访问。
- 异步任务在拿到厂商 `task_id` 后，关页也由服务器用已保存的密钥继续轮询并入库。
- 用户自有渠道统一走本地 Worker，出视频必须提示「不要关浏览器」；掉线后仍由服务器续查（因为 `task_id` 已入库）。
- 平台渠道 Key、积分账本只在服务器（及日后 CF Worker 密钥）。
- 成品入库本站桶后，预览映射只指向本站对象。
- Agent 可运营关闭；默认关闭。
- 支付对账维持现状。

### Non-Goals

- 本期不把平台 Key 下发到浏览器。
- 本期不把 Go 任务队列整段搬到 CF Worker（可在票模型稳定后另开）。
- 不把厂商 CDN 播放地址当永久资源。
- 不在一次 HTTP 里死等视频做完。
- 不在 VPS 上跑 ffmpeg。
- 不把微信支付/支付宝回调这期迁到 CF。
- 不同步请求失败后由服务器重放（避免重复计费）。

| 能力 | 现状 |

| 支付 | VPS 收回调、入账 |
| 轮询开销 | 隔数秒一个小 HTTP，不是 GPU |

## 目标架构

```text
浏览器
  ├─ 编辑画布（本地 + 同步 Postgres JSON）
  ├─ 要票：POST /api/generation-tickets
  ├─ 用户 API：本机 Worker 提交厂商 → 立刻回报 task_id
  └─ 预览：向服务器换私有桶短签名 URL

服务器（鉴权 + 账本 + 续跑）
  ├─ 登录 / 会员 / 积分 / 票 / 幂等
  ├─ 平台渠道：代交佳速（Go Worker；日后 CF 验票后代交）
  ├─ 掉线续跑：凭已存 task_id + 已存密钥轮询
  └─ 入库：下载成品 → 写入本站或用户 R2 → 只存 object key

R2 私有桶
  └─ 上传原片、生成成品、Agent/ffmpeg wasm 静态件（无密钥）

CF Worker（现网已有 origin-proxy）
  └─ 本期继续当域名门；平台代交迁 CF 为后续阶段
```

## 1. 任务票（服务器唯一入口）

每次生成（出图、出视频、拆分镜、Agent 要打模型）必须先开票。

### 开票校验（全部失败则 403/402，不创建可执行票）

| 条件 | 拒绝 |
| --- | --- |
| 未登录 / 会话无效 | 不允许 |
| 会员过期（高级过期且无永久）且该能力要求会员 | 不允许 |
| `creditsEnabled` 且预估费用 > 可用积分 | 不允许 |
| 票 TTL 已过（执行时再验一次） | 不允许 |
| 该 `jti` 已使用 | 不允许（同一票根不能提交两次） |

开票时：**预扣**积分（沿用现有 billing reserve）。执行失败或过期未用：**退预扣**。成功：**转结算**。

### 票载荷（签名，短 TTL，建议 2–10 分钟）

- `jti`：票根，全局唯一  
- `taskId`：对应 `tasks.id`  
- `userId`  
- `exp`  
- `model` / `capability`（image / video / text / storyboard）  
- `maxMicrocredits`  
- `channelScope`：`system` \| `user`  
- `async`：是否允许掉线续跑  

浏览器只拿这张票去提交。**改模型、加费用、换用户必须重新开票。**

### 同一票根不能提交两次

以 `jti` 为幂等键：

1. 开票时写入 `generation_tickets`（或 `tasks` 上唯一 `ticket_jti`），状态 `issued`。  
2. 第一次真正向厂商 **create** 成功（拿到厂商 id 或同步响应）：状态 `submitted`，`jti` 作废。  
3. 任何第二次提交同一 `jti`：直接拒绝，不打厂商。  
4. 同步请求在浏览器侧失败、从未 `submitted`：票过期后退款；**不**自动重放。用户点第二次会开**新票**。

## 2. 两条提交路径

### A. 用户自己的 API（本地 Worker）

- 浏览器用用户保存在设置里的 Key 提交（可经本机 Worker，避免卡 UI）。  
- **异步**（佳速类出图/出视频）：  
  1. 厂商返回 `task_id`；  
  2. **立即** `PATCH` 任务：`providerRequestId` + 渠道 id；  
  3. 出视频 UI **必须提示：不要关闭浏览器**（本机还在传文件/等第一跳）；  
  4. `task_id` 一旦入库，关页后由 **服务器用库里已保存的用户渠道密钥** 继续轮询（用户密钥本就在 `model_channels`，不从浏览器再要一遍）。  
- **同步**：浏览器断线即丢；服务器不补打。提示「同步请求中断不会自动重试」。

### B. 平台渠道（佳速等）

- Key 只在服务器（或日后 CF Worker secret）。  
- 现阶段：开票后仍由 Go Worker 提交 + 轮询（已具备掉线续跑）。  
- 后续：CF Worker 验票签名 → 提交佳速 → 把 `task_id` 写回服务器 → 轮询可留在 Go 或 CF Queue。  
- **禁止**浏览器直持平台 Key。

---

## 3. 关掉浏览器也要轮询入库

适用范围：**仅异步且已成功拿到厂商 `task_id` 并写入服务器的任务**。

流程：

```text
create 成功 → 存 providerRequestId
    → 浏览器可继续轮询展示进度
    → 浏览器消失：Go Worker 按 next_poll_at 领取
    → 厂商成功：把文件拉到目标桶（平台 R2 或用户私有桶）
    → resources 记 bucket + objectKey + provider=s3
    → 任务 succeeded，结账
    → 预览只换短签名，不存厂商 URL
```

失败：明确终态失败才退预扣。查询超时/524 走现有 uncertain，不把厂商可能成功的任务当失败扔掉。

同步请求：**不**进入这条续跑。

轮询本身是小 HTTP，不是重计算。禁止把视频字节经 VPS 中转给用户播放；只在「入库拷贝」时经过一次下载写入 R2。

---

## 4. 素材 URL：私有桶短签名

| 规则 | 说明 |
| --- | --- |
| 桶策略 | 平台 `jiasuapi-canvas` 与个人桶均按 **私有** 使用，不公开 list、不长期公开读 |
| 预览/下载 | 只签发短时 URL（现网 `directResourceURLTTL` ≈ 5 分钟，保持这个量级） |
| 生成参考图 | 开票或提交前由服务器签发短链给本地 Worker / CF Worker 去拉；过期必须重新签发 |
| 禁止 | 把佳速/厂商播放地址写入画布当 `content` 永久字段 |
| 画布 JSON | 只存 `assetId` / `storageKey=resource:{id}` |
| 旧 local 文件 | 迁入 R2 前，签名走现有 `/api/public/resources/:id/file/...` 短链，不改成裸盘路径 |

用户预览：`GET /api/resources/:id/url`（已有 DirectResourceURL 语义）→ 播放签名地址。过期前端再换一张。

---

## 5. 积分不够 / 时间过期

两道门，缺一不可：

1. **开票时**：余额、会员有效期、功能开关。  
2. **提交时 / 续跑领取时**：票 `exp`、`jti` 未使用、预扣单仍有效。过期票作废并退预扣。

Agent 打模型同样走票，不另开「免费循环」。开关关闭时整条 Agent API 403。

## 6. 云端 Agent

| 项 | 口径 |
| --- | --- |
| 后台 | `feature_availability.cloudAgentEnabled`，**默认 false** |
| 开启后 | 进画布或点 Agent：本地没有运行配置则拉取（能力清单、技能摘要、策略版本）再启动 |
| 运行位置 | 对话与工具循环尽量在用户侧；每次真正调模型仍要票 |
| 关页 | 若该轮已开票并提交异步生成，生成续跑仍按第 3 节；**对话循环**关页即停（与「千人 Agent 不堆 VPS」一致） |
| 配置 | 可放 R2 的静态件（SKILL.md、策略版本）；Key 与积分不行 |

## 7. ffmpeg 与支付

- **ffmpeg**：VPS 不承担。浏览器 wasm；核心文件可放 R2，本地没有再拉。  
- **支付 Worker**：留在服务器。回调验签、加积分仍写 Postgres。量小，不作为瓶颈。

---

## 8. 现网 Go Worker 怎么处置

空转（2 秒看一眼队列）可忽略。真正占资源的是「代问上游 + 曾把媒体经服务器中转」。

本期：Go Worker **留下**，专门做：平台渠道提交、**掉线后的异步轮询、成品拉进 R2、结账**。  
用户渠道的 **create** 改到本地 Worker 后，Go 不再替用户 create，只在已有 `providerRequestId` 时 poll + 入库。

## 实施阶段

### P0 — 产品闸门（可先于大改）

- Agent 功能开关默认关；后台可开。  
- 用户渠道出视频确认框：必须提示勿关浏览器；说明异步任务号写入后可由服务器续查；同步中断不重试。  
- 预览禁止新写入厂商 URL；新成功任务入库走 R2/短签名。

### P1 — 票 + 幂等 + 余额/过期

- 开票 API；`jti` 唯一；预扣；exp。  
- 执行/续跑二次校验积分与过期。  
- 同一 `jti` 第二次提交硬拒绝。

### P2 — 用户渠道本地提交 + 立刻回报 task_id

- 本地 Worker 只负责 create。  
- create 成功立刻 PATCH `providerRequestId`。  
- 未回报前关页：视为同步丢失（没有 id 无法代查）。  
- 已回报：Go 续跑 + 拉文件进桶。

### P3 — 私有桶签名一等公民

- 新上传/生成默认 R2，避免降级 local（失败要明确报错，而不是默默写盘）。  
- 参考素材一律短签名。  
- 存量 `local` 迁桶（运维窗口）。

### P4 — 可选：平台提交迁 CF Worker

- 验票、代交佳速、回写 `task_id`。  
- 轮询仍可留 Go。  
- origin-proxy 继续当门，不负责生成。

## 验收

- 积分 0 或会员过期：开票失败，上游无请求。  
- 同一票点两次生成：第二次 409/403，厂商侧只有一次 create。  
- 私有对象不能用过期签名或裸 URL 打开。  
- 用户 API 异步出图：拿到 id 后杀浏览器，任务仍能 succeeded 且资源在 R2。  
- 同步请求中途断网：不出现第二次自动 create。  
- Agent 默认关；打开开关后首次进入会拉配置。  
- 预览播放地址域名是本站签名或 R2 签名，不是佳速临时 CDN。

## 风险

| 风险 | 处理 |
| --- | --- |
| 本地 create 成功但 PATCH id 失败 | 重试 PATCH；失败则任务停在「已请求但未登记」，提供手动粘贴/查询，避免盲目重放 create |
| 用户改了渠道 Key 后续跑失败 | 续跑用 **任务创建时绑定的渠道版本**，不跟当前设置漂移 |
| R2 PUT 失败又降级 local | P3 改为失败可见；与「文件都在桶里」冲突 |
| 短签名过期 | 播放器 403 时静默换票，不把签名 URL 写入 IndexedDB 当永久字段 |
